# 🚀 DDU CareerDrive

**DDU CareerDrive** is a placement portal developed using the **MERN stack** to streamline the **campus recruitment process** at **Dharamsinh Desai University (DDU)**. It bridges the gap between **students** and the **placement cell**, offering a modern, centralized solution for job applications, listings, and recruitment management.



## 🔑 Key Features

- 🔐 **Secure Login** with JWT & bcrypt
- 🧑‍🎓 **Role-based access** for students and faculty
- 📝 **Resume upload** via Cloudinary
- 🎯 **Job filtering** by category, title, salary, and location
- 🧾 **Application tracking** in a personalized dashboard
- 🧑‍🏫 **Faculty dashboard** to post jobs and review applicants


## 💻 Technologies Used

- **Frontend:** React.js + Tailwind CSS  
- **Backend:** Node.js + Express.js  
- **Database:** MongoDB + Mongoose  
- **Authentication:** JWT + bcrypt  
- **File Handling:** Multer + Cloudinary
